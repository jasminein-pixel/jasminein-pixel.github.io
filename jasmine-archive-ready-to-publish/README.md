# Jasmine Archive — Portfolio Website

A responsive editorial-style portfolio for Jasmine Shrestha, built with HTML, CSS, and vanilla JavaScript.

## Files

- `index.html` — all portfolio content and page structure
- `styles.css` — styling and responsive layouts
- `script.js` — mobile navigation interaction
- `.nojekyll` — tells GitHub Pages to publish the static files without Jekyll processing

## Preview locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a **public** repository named `jasminein-pixel.github.io` in the GitHub account `jasminein-pixel`.
2. Extract this ZIP and upload the files in this folder directly to the repository root. Make sure `index.html` is at the top level, not inside another folder.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Once the Pages workflow finishes, open `https://jasminein-pixel.github.io`.

GitHub Pages sites are public. Review the content and contact details before publishing.

## Updating later

Edit the HTML/CSS/JS files in the repository and commit the changes. GitHub Pages republishes the site from the selected branch.
